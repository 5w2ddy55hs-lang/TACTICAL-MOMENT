## 0. 結論

- **確認できた事実**：D-1 は「相手がドリブル中の誤認」ではありませんでした。
  - 選手たちが最後に目撃した接触は **A08 のスローイン**。その後**約6秒間、誰も球に触れていない**転がる自由球でした。
  - その間、B の各選手は「味方が球の2.1m以内にいて、敵はいない」という距離だけの条件で、何度も「自チーム保持」へ切り替わっていました。
  - B01, B03, B06 は support、B02 は advance_support へ。B05 は B01 を見て cover_exchange へ、B01 は B05 を見て support へと**互いに譲り合った**結果、球の1〜2m以内にいながら誰も回収しませんでした。
- **候補 K20**（`decision.mjs` 42行目の1行のみ）：味方が近くにいても、**本人が最後に目撃した接触が自チームの選手によるもの**でなければ「保持」としません。根拠は本人の目撃記憶（誰が、どのチームが、どの部位で触れたか。意図は含まない）だけで、GK は元の規則のままです。
- **結果**
  - 同じDTOでの判断比較：相手が実際に制御していたのに「自チーム保持」とされていた判断を **96% 修正**。誤りは、実際に自チームが制御していた判断の **0.3〜0.5%** にとどまる。
  - 同じ機会でのペア比較（3試合、3,941機会）：攻撃への切替・保持の継続・シュートに有意な変化はなし。自由球の3秒以内の回収 +13（1,542→1,555）、回収までの平均 1.09→1.06秒。
  - **D-1 自体の結果は改善しませんでした**。K20 で保持の揺れは消えましたが、B05 が転がる球の1.1〜1.4m横を約3秒並走して触れない状況は変わらず、最後は B01 から GK へのパスがオウンゴールになりました。
- **判断：採用しません（研究を続ける候補）。** 判断の正しさは大きく改善しましたが、同じ機会での成果の差は小さく、D-1 の主因（受球の実行）は別の問題です。自然試合では味方同士の衝突が +11%、ボールを失った側の2秒以内の奪回が −7% でした。

## 2. 候補 K20（隔離、未採用）

差分は `K20_CODE_DIFF.patch`（`decision.mjs` の1行と保存識別子のみ）。変更しないモジュールは原本を参照します。

```
witnessedOwnTouch = p.role==='GK' || (本人が最後に目撃した接触の選手が全員自チーム)
ourPossession = 見えている保持者 ? そのチーム : (2.1m以内に味方あり && 2.1m以内に敵なし && witnessedOwnTouch)
```

- **使うもの**：本人の `observedTouch`（エンジンが目撃した接触だけを記録し、キックの意図や狙いは含まない）。
- **使わないもの**：世界の真値、他者の意図、未来、共有された受け手ID。
- **情報不足の扱い**：目撃なし、相手の接触、同時接触は「不明」とし、従来の「保持ではない」側の判断に任せます。cover / 追走の点数は元のままで、新しい係数は加えていません。
- **触れないもの**：相手保持の判定（theirPossession）、パス飛行中、GK（GK は ちゃつぴ側の担当のため除外。初版で GK に効くことが判明し、比較を行う前に除外しました）。

## 4. 改善・副作用・未検証

- **改善（確認済み）**
  - 相手が制御しているときや自由球のときに「自チーム保持」とする誤認が、判断単位でほぼ消えました（96%修正）。
  - 攻撃形への誤った切替と、support↔cover の揺れも減りました。
  - 同じ機会で比べても、攻撃への切替・保持の継続・共同プレスは壊れていません。自由球の回収はわずかに速くなりました。
- **副作用（確認済み、または可能性）**
  - 本人が目撃していない味方の制御直後に、攻撃への切替判断が遅れる（実際に自チームが制御していた判断の 0.3〜0.5%、FREE2）。
  - 自然試合で、味方同士の衝突 +11%、2秒以内の奪回 −7%（support → receive/intercept が増え、球へ向かう選手が増えた可能性。分布の比較のため因果は未確定）。
- **改善しなかったこと**
  - D-1 の結果。主因は、転がる球の横を並走して触れない受球の実行で、元はスローインの長い球です。
  - パス飛行中の陣形（I18）。
- **未検証**：GK への適用（除外しているため）、zonal ON / CK枝との組合せ、陣形・能力差・`formationAnchor` を持つ選手構成、Node 24、実機。相手保持の判定の対称的な誤認（相手が球に近いだけ）は扱っていません。

## 5. 原因仮説と次の最小検証

1. **仮説（裏付けあり）**：距離だけの保持判定が、自由球と相手のパスの球で「自チーム保持」を作り、近くの味方同士が譲り合う。→ K20 で判断の誤認は消えました。結果への効果は小さいです。
2. **仮説（未検証）**：D-1 の失点は、受球の実行（並走する球に足が届かない）と、スローインの長い転がる球によるもの。→ ちゃつぴ側の受球準備・スローインの担当です。
3. **次の最小検証**（実行していない）
   - K20 の「不明」の間は support を使わないが、追う点数の −1.5 減点は残す分離版を作り、衝突の増加が「追う選手の増加」から来ているかを、同じ機会で比べる。
   - 「目撃していない味方の制御」で遅れた判断（234 / 146件）を時系列で再現し、遅れの長さと実際の移動への影響を測る。

## 6. ちゃつぴ側への引渡し（実装変更なし）

- **スローイン**：D-1 の起点は A08 のスローインの長い球。約6秒間、誰も触れずに PA まで転がりました（`probe/D1_base.json`、tick 94701〜94823）。
- **受球準備**：B05 が receive のまま、転がる球の 1.1〜1.4m 横を約3秒並走して触れない（94765〜94821。両方の版で再現）。
- **GK・パスの出口**：K20 の D-1 では、B01 の B00 へのパス（94840）がオウンゴールになりました。GK の `goalkeeperPlan` も `ourPossession` を使うため、K20 では GK を除外しています。GK に同じ根拠を使うかどうかは GK 担当の判断に委ねます。
- 目撃していない味方の制御の遅れ（FREE2 型）は、受球後の継続の研究とも関係する可能性があります。

## 0. 結論

1. **目撃されなかった味方の制御（K20 で「不明」になる判断）**
   - 2試合で 234件（67場面）と146件（52場面）。
   - 認識が更新された場合、更新までの中央値は **4〜5tick（約1判断周期）**。
   - 同じ機会で比べると、攻撃形の判断は約10%減りますが、**実際の前進の差は2秒で 0.1〜0.2m**。6秒後の保持は場面ごとに双方向へ動き、一方的な損失は見られませんでした。
   - 約半数は相手との同時接触で、「不明」は情報として正しい状態です。修正するだけの根拠がないため、**修正していません**。
2. **自然試合で見た副作用**
   - 2秒以内の奪回の減少：同じ機会では**再現しません**（709→708）。分岐後の機会の違いと判断します。
   - 味方同士の接触の増加：同じ機会でも**再現しました**（自由球で +9.3%）。増加分の 277/316 件に K20 で変わった判断が関わり、receive+receive の組み合わせが +214 です。D-1 の「相互の譲り」の裏返しで、近くの2人が同じ自由球へ同時に向かっています。
3. **新候補 L21**（事前登録）：K20 で「不明」のときに限り、**今見えていて、自分より球に近く、明らかに回収に向かっている味方**（1.1m以内、または相対接近 0.5m/s 以上）にだけ球を譲ります。
   - 自由球での接触増加はほぼ解消：基準 1,469 / K20 1,605 / L21 1,479。
   - 保持判断の改善は K20 と同じく維持。
   - 保持の入れ替わり後、6秒後も保持している割合は L21 で −10/1,154。自由球でのオウンゴールは K20 と同じく 9→12。
   - D-1 は L21 でも結果が変わりません（B05 が回収に失敗する）。
4. **判断：K20・L21 ともに正式採用は保留。** L21 は K20 の副作用を解消しましたが、効果は小さく、6秒後の保持にわずかな低下があり、D-1 の主因は別の問題です。

### 途中で判明した訂正
**K20報告の FREE2 の説明は誤りでした。** K20報告では「奪取を目撃していない味方が cover のまま」としましたが、実際には次のとおりです。
- K20 の実行で、B の全員が自チームの接触を目撃していた。
- 2つの実行は奪取の前（tick 9983）から分岐しており、support の減少は「近くの味方」の条件そのものが成立しにくくなった（cover の割合 17→53）ことによる。

したがって FREE2 は「目撃されなかった制御」のコスト例ではありません。K20 の記録は保持し、訂正はこの報告に記載します（`eval/free2_correction.txt`）。

## 3. 新候補 L21（隔離、事前登録：`PREREGISTERED_L21.md`）

差分：`L21_CODE_DIFF_vs_I17.patch`、`L21_CODE_DIFF_vs_K20.patch`（K20 に2行と、点数式の条件1か所を追加）。

```
unknownPossession = 見えている保持者がいない && 2.1m以内に味方 && 2.1m以内に敵なし && 自チームの接触を目撃していない
evidentCollector  = unknownPossession && 次の条件をすべて満たす味方がいる：
                    今見えている（seenTick===tick）、自分より球に近い、
                    (球まで1.1m以内 || 観測速度による球への相対接近 ≥ 0.5m/s)
追う点数の −1.5 を (ourPossession || evidentCollector) のときに適用
```

- 「明らかに回収に向かっている味方」だけに譲るため、遠い側だけが譲ります。相互の譲り（D-1）は戻りません。
- 球の横を並走しているだけの味方（相対接近 ≈ 0）には譲りません。
- 根拠は本人の観測した位置と速度だけです。未観測の保持を真実として扱わず、「不明」は不明のまま、追う判断の重なりだけを調整します。
- 1.1m と 0.5m/s は比較前に固定し、比較後に調整していません。

## 4. 改善・悪化・遅れ・未検証

- **L21 で改善したこと**：K20 の自由球での接触増加の解消（同じ機会：1,605→1,479、自然試合：6,618→5,994）。保持判断の改善（相手のパス中・自由球での攻撃形の誤り）は K20 と同じ水準を維持。共同プレスと競り合いは保持。
- **悪化、または悪化の可能性**
  - 保持の入れ替わり後、6秒後も保持している割合：基準 570 → L21 560（−1.8%）。
  - 自由球でのオウンゴール 9→12（K20 と同じ。件数が少ないため未確定）。
  - 自然試合で「中央が空いた→シュート」が 18→25、得点が 87→95（分岐後の分布の差で、因果は未確定）。
- **遅れ**：目撃されなかった味方の制御による攻撃判断の遅れは、中央値で1判断周期（4〜5tick）。L21 でも同じです（攻撃形の判断の数は K20 と同一）。
- **改善しなかったこと**：D-1 の結果。B05 が転がる球を回収できないという、受球の実行の問題です。
- **未検証**：GK への適用、zonal ON / CK枝との組合せ、陣形・能力差、Node 24、実機。相手保持の判定の対称的な誤認も扱っていません。

## 5. 採否と次の最小検証

- **K20・L21 ともに保留**（正式採用しない）。保持判断の正しさの改善は明確ですが、同じ機会での試合上の成果は小さく、L21 には6秒後の保持のわずかな低下があります。
- **次の最小検証**（実行していない）
  1. L21 で6秒後の保持が変わった場面（基準で保持、L21 で失う）を抽出し、時系列で原因を特定する。
  2. ちゃつぴ側の受球実行の改善を受けた後、D-1 型（自由球の並走回収）で K20 / L21 を再評価する。保持判断より先に、回収そのものが成立するかが前提です。
  3. 再開キックの見落とし（23 / 25件）について、再開を与えられたチームを本人の記憶として持たせるかを、保存スキーマ変更の可否と合わせて別途検討する。

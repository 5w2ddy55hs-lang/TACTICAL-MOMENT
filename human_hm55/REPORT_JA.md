**結論: FH54 の顔・髪と Reference04 の胴体を手直しする方法はやめ、頭・胴体・髪・テクスチャ・骨・ウェイト・動作をすべて独自に作り直しました（HM55）。**

## 3. 優先①：首の接続・ウェイト・動作時の隙間

### 方式

- **継ぎ目を作らない構造:** 首は頭部メッシュの一部です。襟の内側に隠れる「差し込み」まで続いていて、胴体側の肌とは接していません。そのため、首を回しても肌と肌のあいだに隙間は生じません。
- **ウェイト:** 首の下端（襟の中）は胸の骨に 100%、顎の下から上は頭の骨に 100%、そのあいだを首の骨へ滑らかに移します。顎の下の約 3cm でなめらかに変化させ、顎の線が首に引っ張られないようにしました。
- **襟:** シャツの襟は首から 10〜20mm 離れた輪で、首の付け根を囲む布の輪をもう一つ設けました。首を大きく回しても、首がシャツを突き抜けません。

### 実測（`QA_TABLES55.md` §2）

| 動作 | コマ | 胸に対する頭の回転 最大 | 襟の隙間 mm | 首×シャツの交差 | 襟から中が見える光線 |
|---|---|---|---|---|---|
| 静止 | — | 0° | 11.3〜15.8 | 0 | 0/27 |
| 待機 Idle | 61 | 3.6° | 11.3〜15.8 | 0 | 0/27 |
| 走る Run | 21 | 10.7° | 11.4〜16.3 | 0 | 0/27 |
| 蹴る Kick | 41 | 24.9° | 10.8〜16.4 | 0 | 0/27 |
| 首振り LookAround | 101 | **66.1°** | 10.1〜20.5 | 0 | 0/27（P1・P3 は 2/27） |
| スローイン ThrowIn | 46 | 8.9° | 11.2〜15.9 | 0 | 0/27 |
| ヘディング Header | 43 | 44.9° | 10.3〜16.8 | 0 | 0/27 |

- 4 つの顔それぞれで全動作を測りました。首×シャツの交差はすべて 0 です。
- 襟の隙間は 10〜20mm あります。これは「首と襟のすき間」で、肌の継ぎ目ではありません。
- **見通しの光線:** P1（面長）と P3（細面）では、首振りのどこかのコマで 27 本中 2 本が 9cm 以内で肌に当たりませんでした。見える範囲はごく狭いですが、襟の中の暗い部分がのぞく可能性があります（未解決）。
- ウェイトの合計は全頂点で 1.0、1 頂点あたりの骨は最大 3 本（頭）・2 本（胴体）です。

**比較画像:** `M06_neck_motion_P0_H2.jpg`、`M06_neck_motion_P2_H4.jpg`（静止・左右・見上げ・うつむき・傾き・ヘディング・スローインを、正面・側面・背面・上から）。研究用の参照との並びは `M07b`（公開不可フォルダ）。

## 4. 優先②：肌色と継ぎ目

- 顔・首・腕・手・脚の肌を、同じ関数 `skin_base(tone)` と同じ陰影の処理から作りました。顔ごとの色調（T1〜T3）は、その選手の腕と脚にも使います。
- 頭と胴体の境目は襟の中にあるため、**肌どうしが接する継ぎ目はありません。** 頭のテクスチャの首の後ろの UV の継ぎ目では、色の差は平均 0.003（sRGB）です。

| 顔 | 色調 | ΔE 首−頬 | ΔE 首−前腕 | ΔE 首−膝 |
|---|---|---|---|---|
| P0 | T2 | 1.63 | 0.86 | 3.39 |
| P1 | T3 | 4.39 | 0.15 | 2.35 |
| P2 | T1 | 3.98 | 0.60 | 3.33 |
| P3 | T2 | 1.05 | 0.99 | 3.51 |

- ΔE は焼き込んだ陰影を含む最終テクスチャの平均です。膝との差（2.4〜3.5）の多くは、膝のくぼみの陰影と赤みです。
- 頬との差（P1・P2 で約 4）は、髭（P1）と頬の赤み（P2）を意図して入れたためです。

## 5. 優先③：耳まわりの髪と描画

- 髪は HM55 の頭の形状そのもの（耳を含む）に対して作り、耳とは別の殻として交差を検査しています。

| 項目（16 組） | 結果 |
|---|---|
| 髪と頭（耳を含む）の三角形交差 | **すべて 0** |
| 生え際の縁の浮き（中央値） | 1.08〜1.38mm |
| 生え際の縁の浮き（最大） | 3.05mm |
| 耳の近く（方位 58〜102°）の縁の浮き（最大） | **1.57mm** |
| 髪と耳の最短距離 | 3.3〜11.6mm（髪が耳に食い込まず、耳から大きく浮いてもいない） |

- **描画（three.js 0.186.1、ヘッドレス Chromium + SwiftShader）:** 半透明の毛束を最悪の順で描いても、画像の変化は 0〜0.04% でした。ページのエラーは 0 件です。
- ユニフォームの材質は両面描画にしました。袖口・裾・ソックスの口から内側が見えるためです。片面描画のままだと、ブラウザで約 7% の画素が抜けていました（修正後、肌と頭だけを片面にしたときの差は 0.9% で、輪郭の縁です）。

## 6. サッカー動作での確認

- 動作 6 本（30 コマ/秒）: 待機 2.0 秒、走る 0.7 秒（ループ）、蹴る 1.37 秒、首振り 3.37 秒、スローイン 1.53 秒、ヘディング 1.43 秒。

### 動作中の布と肌の重なり（残る問題）

静止時は、肌とユニフォームの交差は 0 です。動作中は次の重なりが残ります（`QA_TABLES55.md` §2）。

| 動作 | 最大の対数 | 内訳 |
|---|---|---|
| 待機・首振り | 10 | 腕の付け根がシャツの脇に入る |
| 走る | 39 | 膝裏がソックスの上端に入る 26、腕とシャツ 11 |
| 蹴る | 29 | 膝裏とソックス 27 |
| ヘディング | 26 | 膝裏とソックス 26 |

膝を深く曲げたときのソックス上端と、腕を体に寄せたときの脇です。どちらも布の内側に肌が入る形で、外からはほぼ見えませんが、角度によってはのぞきます。補助の骨（膝・肩の補正）や、布側のウェイトの調整が次の課題です。

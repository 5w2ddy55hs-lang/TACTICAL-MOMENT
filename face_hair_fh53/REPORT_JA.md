## 0. 要約

- **作ったもの:** 顔 3案（F1〜F3）と髪 4案（H1〜H4）を、実際の 3D データとして作りました。
  - 形式は Blender の .blend と、書き出し後に確認した .glb です。
  - FACE52 の顔（F0）と髪（H0）も含めた **顔4 × 髪5 = 20 通り** を、すべて GLB に書き出し、再読込と交差検査を行いました。
- **新しい髪 4案:** cap（頭皮側の殻）とカード（毛束の板）を、頭の形から作り直しました。
  - FACE52 の課題のうち、**前髪中央の V 字**、**帽子のように浮いた cap の縁**、**頭頂の角張り**、**襟足の水平な帯** は、構造の段階で無くなっています。
  - **新しい髪 H1〜H4 を使う 16 通り** では、**髪と皮膚の三角形交差 0**、**cap とカードの交差 0** です。
  - **H0（FACE52 原本の髪）を使う 4 通り** は 0 ではありません。髪×皮膚は F0×H0 が 51 対、F1〜F3×H0 が 64 対、cap×カードは 8 対です。これは FACE52 原本の状態で、対照として残しています。
  - **cap の外に出た皮膚点** は 20 通りとも 0 です。
  - 判定方法:
    - 交差は、GLB の各プリミティブ同士の BVH 三角形交差（epsilon 0）
    - 皮膚点は、皮膚 33,120 点の放射方向判定
    - 詳細は `qa/QA_TABLES.md` を参照

> **訂正（2026-11-06 追記）:** 初版では、この項目を「20 通りすべてで 交差 0」と書いていました。QA 表と一致しないため、上のとおり訂正します。測定値そのものは変わっていません。
- **残った課題（詳細は §4・§8）:**
  - カード同士の交差が多い（H1 209 / H2 14 / H3 222 / H4 400 対。FACE52 は 7 対）。
  - H1 の耳の上で毛先が絡む。
  - H3 の前の生え際で、斜光時にカードの根元が段差に見える。
  - 短い髪型（H2/H3）では、FACE52 の尖った耳と、後頭部の皮膚の継ぎ目が見えてしまう。
- **Blender の版:** 4.0.2 は入手できなかったため、**4.2.23 LTS** で制作しました。成果の .blend を 4.0.2 で開けるかは確認していません。

### 顔（テクスチャは FACE52 のまま。形だけ変更）

| ID | 狙い | 主な変更（皮膚の最大変位） |
|---|---|---|
| F0_FACE52 | 原本（比較用） | なし |

### 髪（新規ジオメトリ。テクスチャはスクリプトで新たに生成）

| ID | 狙い | 構成 |
|---|---|---|
| H0_FACE52 | 原本（比較用） | cap 1752 + カード 672 三角形 |
| **H1_STANDARD_REBUILT** | H0 の輪郭を受け継いで作り直したもの。帽子状の縁・V 字・頭頂の角・耳前の段差・襟足の帯を、構造から無くす狙い。 | cap 1836 + カード 45 枚（360 三角形） |
| **H2_SHORT_CROP** | 短髪。耳と襟足を出し、シルエットを最も小さく締める。耳前は短いもみあげのみ。 | cap 1836 + カード 12 枚（48 三角形） |
| **H3_SWEPT_BACK** | 前髪を上げて後ろへ流す。額を出し、前頭部に高さを持たせ、側頭部は締める。 | cap 1890 + カード 30 枚（324 三角形） |
| **H4_SIDE_SWEPT_FRINGE** | 片分けの長めの前髪。分け目は向かって左で、前髪が額を斜めに横切る。襟足は長め。左右非対称。 | cap 1917 + カード 43 枚（452 三角形） |

**髪の作り方**（`scripts/build_hairs.py`）:

1. **頭蓋の代わりになる面を推定:** FACE52 の皮膚には頭頂から後頭部にかけて穴があります。その部分は、FACE52 cap をぼかして 7 mm 内側へ寄せた形を基準にしました。皮膚との境目の残差は調和補間で埋め、皮膚と連続させています（cap より内側に 5〜28 mm、中央値 12 mm）。
2. **生え際:** 制御点で決め、つむじ（または流れの起点）を中心とする極座標の格子で cap を作りました。生え際がそのまま最外周の輪になります。
3. **毛の流れと UV:** 流れの軸を中心とする極座標から UV を計算しました。テクスチャは継ぎ目なく繰り返す筋模様です。
4. **生え際のぼかし:** 頂点 alpha で行い、**下に皮膚がある場所だけ** で薄くしています。頭蓋の穴の上で半透明にすると頭の内側が透けて見えるためです。H2 の襟足の硬い線はこれで解消しました。
5. **めり込みの解消:** 皮膚を密に標本化した点（33,120 点）と三角形交差（BVH）の両方で検査し、cap とカードを放射方向へ押し出しました。押し出しは隣接頂点へなだらかに分散させ、突起ができないようにしています。
6. **カード:** 毛の流れの線に沿って配置しました。耳の縁に達したところと、生え際の外から cap へ戻り込むところで打ち切っています。
7. **法線:** cap とカードで同じ「髪の面」から法線を取っています。三角形の向きもその法線と一致させ、根元と cap の法線のずれが出ないようにしました。

**テクスチャ:**

- `TMH53_CAP_STRANDS_512.png`（平均 RGB 0.093。FACE52 cap は 0.095）
- `TMH53_CARD_STRANDS_512.png`（4 種類の毛束の帯）
- どちらも `make_hair_textures.py` で乱数の種を固定して合成しました。既存画像の画素は使っていません。

### 名前と組み合わせ

- 頭部 GLB は `TM_FH53_F{0..3}_H{0..4}.glb` の **20 通りすべてを書き出し、すべて検査しました**（§5）。
- 未検証の組み合わせはありません。ただし、検査の範囲は静止状態に限ります（§8）。

| **前髪中央の V 字・帽子状の輪郭・頭頂の角** | H1〜H4 のすべてで V 字はありません。上から見た輪郭は丸く、頭頂の角はありません。 | H1 の前髪は櫛の歯のように規則的です。**H3 は grazing 光で、前の生え際にカード根元の段差が見えます。** H1/H4 は上から見ると数枚のカードが外へ出ています（めり込み解消の押し出しによる。最大 6.0 / 8.7 mm）。 |

- FACE52 の cap には、頭蓋の穴の上で alpha が 0.99 未満の頂点が **134 個** ありました。
- ただし、位置はすべて **後頭部の上方（方位 ±125〜165°、仰角 24〜58°）** で、耳前ではありません。
- したがって、**耳前の暗部の原因としては裏付けられていません。** 新しい髪 4案では、この頂点数は 0 です。

## 7. 書き出し方法

- **新しい髪（H1〜H4）と顔（F1〜F3）:** Blender の glTF 書き出しを通常どおり行いました（`export_extras=True`）。
  - **canonical_cap は適用していません。** 頭皮の形が FACE52 と違うためです。
- **H0 を含む組み合わせ（F0〜F3 × H0）:** 通常の書き出しの後、FACE52 の最終 GLB から cap のプリミティブをバイト単位で移植しています（`glb_io.graft_primitive`）。
  - FACE52 の `canonical_cap` と同じ考え方です。
  - 移植の前に、corner 展開した POSITION の完全一致を確認しています。UV と頂点色も完全一致で、法線の差（最大 6.8e-3）は canonical cap による法線の復元分です。
- 元の `build49_v3.py` は、同梱されていない FACE47 の .blend の SHA を読み込み時に検査するため、そのまま import できません。この処理は再実装です。

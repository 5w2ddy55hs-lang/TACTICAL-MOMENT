## 0. 要約

代表の 1 体（顔 P0 × 髪 H2 × ユニフォーム A）の形状を作り直し、HM55 と同じカメラ・姿勢・照明で比べました。

| 指示 | 結果 |
|---|---|
| ① 首を肩・胸・背中へ自然につなぐ | 首の付け根に胸鎖乳突筋と僧帽筋の形を入れ、根元をなだらかに広げました。シャツの肩（ヨーク）は首の形に沿わせ、襟は首の表面から 9mm の位置に作りました。全 6 動作・全 313 コマで、首とシャツの交差は 0 です。襟と首の隙間は、動作中も 8.31〜9.52mm でほぼ一定です（HM55 は 9.47〜15.83mm で、首振りで開いていました） |
| ② 肩当てのような肩と箱状のシャツ | 肩の盛り上がりを三角筋の形に置き換え、肩の線を首から下がる傾斜にしました。胴は胸郭・大胸筋・広背筋・腰のくびれで作り直し、正面と横で厚みと輪郭が出るようにしました。腕とシャツの交差は、HM55 では全動作（Idle は 61 コマすべて）にありましたが、HM56 では Kick だけ（最大 13 対、41 コマ中 19 コマ）です |
| ③ 膝・ふくらはぎ・足首・スパイク | 膝のお皿と内側の筋肉、ふくらはぎの 2 つの山、アキレス腱、細い足首を形にしました。スパイクは低いつま先、かかと、ソール、靴ひもの柄にしました。頭の大きさは変えていません |
| ④ 顔のまぶた・頬・唇・顎 | まぶた（上下）・頬骨・頬・上唇の山・下唇・唇の下のくぼみ・顎の先を形状で追加しました。顔の三角形は 1,988 → 4,678 です。1 回目の結果で目の下が暗いくまに見えたため、目の下を埋める形を足して作り直しました（§4） |
| 骨・動作 | 骨 22 本と動作 6 本は HM55 と**バイナリで同一**（396 チャンネル、時刻と値の差 0）。ウェイトは同じ規則で作り直し、合計はすべて 1.0 |
| サイズ | GLB 2,202,012 → 2,308,544 バイト、三角形 6,478 → 9,200 |

**残った問題**（§6 に詳細）: 膝を曲げたときの膝とソックスの交差（HM55 と同程度）、Kick での腕とシャツの交差、首振りで首の皮膚が大きく伸びる、スローインで脇に袖の内側が見える（新しく出た問題）、袖の付け根の小さな折れ目、顔の三角形が 2 倍以上になったこと、顔の印象（年齢が上に見える）。

**確認していないこと:** iPhone 実機、試合エンジン、GPU での表示、Blender 4.0.2、見た目と権利の最終判断。

## 2. 体の変更（`scripts/hm_body.py`、`scripts/hm_head.py`）

体はすべて距離関数（SDF）で形を定義し、輪切りの格子でメッシュにしています。UV・テクスチャ・ウェイトも同じスクリプトから生成します。

### 2.1 首 → 肩・胸・背中

- 首に胸鎖乳突筋（耳の後ろから鎖骨の内側へ）と僧帽筋の上部（首の後ろから肩へ）を足し、根元をなだらかに広げました（`hm_head.py` の `scm_*`、`trap_*`）。
- 首の根元の輪を細かくし、首から肩へのへこみが角にならないようにしました。
- シャツの肩（ヨーク）は首の形を 9.5mm 外側へずらした面で作りました。襟の輪は、首の表面から実距離 9mm の位置を輪ごとに探して置いています（`collar_ring`）。これで首の太さが場所によって違っても、襟と首の隙間がそろいます。
- 首の付け根は、襟の高さまで胸の骨に固定しました（`NECK_BASE_Z`）。首を振ったときに首の根元がシャツを突き抜けないためです。首の中ほどは Neck の骨が受け持つよう、ウェイトの配分を変えました。

### 2.2 肩とシャツ

- 肩の丸い塊をやめ、腕の向きに沿った三角筋の形にしました（`deltoid`）。シャツの袖は三角筋より少し大きい円錐で、肩から自然に続きます。
- 胴は、腰（裾）・くびれ・胸郭・上胸・大胸筋・広背筋・僧帽筋で組み立て直しました。正面では胸から腰へ細くなり、横では胸と背中に厚みが出ます。
- ユニフォームの材質を両面表示にしました（襟や袖の内側が見えたときに抜けて見えないように）。

### 2.3 膝・ふくらはぎ・足首・スパイク

- 膝: お皿、大腿骨の両側の出っ張り、内側広筋。
- ふくらはぎ: 内側と外側の 2 つの山と、アキレス腱。足首は細くしました（半径 33mm）。
- スパイク: つま先を低くし、かかとの芯とソールの板を付けました。靴底は高さ 3mm で平らに切っています。テクスチャに靴ひも・ベロ・灰色のソールを描きました（ロゴは入れていません）。

### 2.4 頭の大きさ

頭の大きさと身長（1.79m）は HM55 と同じです。頭を小さくして体の違和感をごまかすことはしていません。

## 3. 骨・ウェイト・動作

- 骨 22 本と動作 6 本（Idle / Run / Kick / LookAround / ThrowIn / Header、30fps）は、HM55 の定義をそのまま使いました。書き出した 2 つの GLB を `summarize56.py` でバイナリ比較し、骨の名前と順番、静止姿勢、逆バインド行列、396 チャンネルの時刻・値・補間がすべて一致しました（`qa/rig_identity56.json`）。
- 骨組みと動作の名前は HM55 のままです（`TM_HM55_Rig`、`TM_HM55_Run` など）。試合側で HM55 と HM56 を差し替えても、同じ名前で再生できるようにするためです。
- ウェイトは、HM55 と同じ規則で新しい体形に作り直しました。読み直した GLB で、全頂点の合計が 1.0、1 頂点あたりの影響は胴体 2、頭 3、髪 1 本までです。

## 4. 顔（`scripts/hm_head.py`、`scripts/hm_texture.py`）

- 追加した形: 眼球のふくらみ、上下のまぶた、頬骨、頬、上唇の山（人中と上唇結節）、下唇、口角のくぼみ、唇の下のくぼみ、顎の先。
- 顔の格子を細かくしました（顔の部分で縦 約 3mm 間隔）。顔の三角形は 1,988 → 4,678 です。
- **1 回目の結果の問題と修正:** 1 回目は、下まぶたのふくらみと頬骨のあいだに溝ができ、陰影で目の下が暗いくまに見えました。唇の下のくぼみも深く、口が 2 本あるように見えました。目の下の溝を埋める形を足し、下まぶたを薄くし、唇の下のくぼみを浅くして作り直しました。比較画像と数値はすべて作り直した後のものです。
- 顔の陰影の焼き込み（AO）は 0.45、目の下の影のテクスチャは 0.10 に下げています。

**まだ残っている印象:** 改良前より彫りは深くなりましたが、頬骨の下に横向きの影が出て、年齢が上に見えます。下から見ると頬に段があります（`C02` の「下から」）。

## 5. 確認の方法と結果

### 5.1 比較画像（同じカメラ・姿勢・照明）

`compare56.py` が、HM55 と HM56 の GLB を同じ手順で読み込み、同じカメラ・照明・サンプル数・姿勢で 1 枚ずつ描画します。iPhone 向けのシートは `compose56.py` が幅 1080px で縦に並べます。

| シート | 内容 |
|---|---|
| C01 | 全身：正面・横・斜め・背面（A ポーズ） |
| C02 | 顔：正面・斜め・横・下から |
| C03 | 首から肩・胸・背中：正面・斜め・横・背面 |
| C04 | 膝・ふくらはぎ・足首・スパイク |
| C05 / C05b | 首振り左右・見上げ・うつむき・ヘディング・スローインの姿勢での首と襟（前と後ろ） |
| C06 | 動作中の脇とシャツ、膝裏とソックス（Kick・Run・Header の複数コマ） |
| C07 | 走る・蹴る・ヘディング・スローインの複数コマ |
| C08 / C09 | 試合中の距離（中継カメラ: 約 25m 先、高さ 12m、望遠）と、幅 48・72・96px での表示 |

### 5.2 連続再生

- `anim_video56.py` が、Run（2 周）・Kick・Header・ThrowIn の全コマを全身で、LookAround の首と Kick の膝を拡大で描画し、HM55 と HM56 を左右に並べた動画にしました。
- MP4 は H.264・yuv420p・faststart で、iPhone で再生できる形式です。ただし **iPhone 実機では再生を確認していません。**
- ブラウザ（three.js、ヘッドレス Chromium + SwiftShader）でも、Run・Kick・Header・LookAround をコマ送りで連続再生して録画しました（`HM56_browser_threejs_playback.mp4`）。GPU のある実機ではありません。

### 5.3 動作中の全コマの実測（`verify_motion56.py`）

書き出した GLB を読み直し、6 動作の全 313 コマで姿勢を付けて測りました。HM55 も同じスクリプトで測っています。

| 項目 | HM55 | HM56 |
|---|---|---|
| 首 × シャツの交差 | 0 | 0 |
| 襟と首の隙間 | 9.47〜15.83mm | 8.31〜9.52mm |
| 襟の中が見える光線（51 本中、各動作の最大） | 0〜3 | 0〜2（ThrowIn・Header で 2） |
| 腕 × シャツの交差 | 全 6 動作のうち 6 動作（10〜15 対） | Kick のみ（13 対・19 コマ、腕 × 肩 2 対・14 コマ） |
| 膝・太もも × ソックスの交差 | Run 29、Kick 29、Header 26 | Run 25、Kick 24、Header 26 |
| 袖口と腕の隙間 | 5.43〜9.03mm | 5.43〜9.03mm |
| ソックスの口と脚の隙間 | 0.66〜2.29mm | 0.25〜2.37mm |
| パンツの裾と太ももの隙間 | 7.68〜30.0mm | 10.79〜33.36mm |
| 頭の辺の伸び（LookAround、1% / 99%） | 0.64 / 1.89 | 0.59 / 2.88 |

動作ごとの表は `qa/QA_TABLES56.md` の §4 にあります。

### 5.4 その他

- 髪（H2）: 頭との交差 0、生え際の縁の浮き 中央値 1.09mm・最大 2.44mm（耳の近くは最大 1.49mm）、髪と耳の距離 7.32mm。
- 肌の色差（ΔE76）: 首と前腕 0.6、首と膝 3.06、首と頬 1.68。
- glTF Validator と ブラウザの結果は `qa/gltf_validator.json`、`qa/webtest55_result.json`、`qa/webtest55_analysis.json` にあります（§5.5）。

### 5.5 ブラウザと glTF Validator

- **glTF Validator 2.0.0-dev.3.10:** 代表の GLB と部品の GLB 4 本、すべてエラー 0。警告は `NODE_SKINNED_MESH_NON_ROOT`（スキン付きメッシュが骨組みのノードの子になっている）だけで、親のノードは移動・回転・拡大なしです。HM55 と同じ警告です。
- **three.js 0.186.1（ヘッドレス Chromium + SwiftShader、GPU なし）:** 骨 22 本、動作 6 本を読み込み、Run 21・Kick 41・Header 43・LookAround 101 コマをコマ送りで連続再生しました。ページのエラーは 0 件です。22 体を同時に描くと 197,966 三角形・描画呼び出し 158 回で、1 コマ 2.56〜4.10ms でした（ソフトウェア描画での参考値で、実機の速度ではありません）。
- 髪の描画順を入れ替えても、画素の変化は最大 0.006% でした。

## 6. 残った問題（未解決）

1. **膝とソックスの交差:** 膝を深く曲げる Run・Kick・Header で、膝の皮膚がソックスの口の内側に入ります（最大 24〜26 対）。HM55 からほとんど減っていません。ソックスの口を膝から離すか、膝のウェイトを見直す必要があります。
2. **Kick の腕とシャツ:** 振り上げた腕が、脇でシャツと交差します（最大 13 対、41 コマ中 19 コマ）。他の 5 動作では 0 です。
3. **首振りでの首の伸び:** LookAround で、首の皮膚の辺が最大 2.88 倍に伸びます（HM55 は 1.89 倍）。首の根元を胸に固定したため、ねじれが首の中ほどに集まっています。動画では首が少しロープのようによじれて見えるコマがあります。
4. **スローインで脇に袖の内側が見える:** 腕を高く上げると、脇の下に袖の内側（暗い面）が見えます（`C06` の「脇（スローイン）」）。HM55 にはなかった問題です。襟の中が見える光線も ThrowIn で 51 本中 2 本あります。
5. **肩の小さな折れ目:** 袖の付け根の上に、小さな折れ目が残っています（`C03`）。
6. **顔:** 立体感は出ましたが、頬骨の下の影で年齢が上に見えます。下から見ると頬に段があります。
7. **三角形の増加:** 顔が 1,988 → 4,678、全体が 6,478 → 9,200 三角形になりました。22 人を同時に描くと、ブラウザの計測で約 20 万三角形です。遠目の表示用に、顔を軽くした版（LOD）が必要かもしれません。
8. **展開していないもの:** 顔 P1〜P3、髪 H1・H3・H4、ユニフォーム B の組み合わせは作っていません。

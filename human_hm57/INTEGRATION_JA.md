# HM57 をゲームに接続するための情報（正式統合はしていません）

この文書は、HM57 の GLB を TACTICAL MOMENT の試合演出に組み込むときに必要な情報と、まだ対応していない点の一覧です。**試合エンジンへの組み込みはしていません。** ここに書いた動作の確認は、Blender（bpy 4.2）と、ブラウザの three.js（ヘッドレス Chromium＋ソフトウェア描画）で行ったものです。数値の出典は `qa/QA_TABLES57.md` と `qa/*.json` です。

## 2. 座標と単位

- 単位はメートル。原点は両足の間の地面。身長は約 1.78m。
- glTF の座標系（+Y が上）。選手の正面は glTF の **+Z** 方向（Blender では −Y）。選手の左手が glTF の +X。
- 静止姿勢は A ポーズ（腕を下に 24° 開いた状態）。

## 3. 骨（22 本、すべての GLB で同じ名前・順番・静止姿勢）

```
Root
└ Hips
  ├ Spine └ Chest ├ Neck └ Head
  │               ├ Shoulder_L └ UpperArm_L └ LowerArm_L └ Hand_L
  │               └ Shoulder_R └ UpperArm_R └ LowerArm_R └ Hand_R
  ├ UpperLeg_L └ LowerLeg_L └ Foot_L └ Toes_L
  └ UpperLeg_R └ LowerLeg_R └ Foot_R └ Toes_R
```

- 骨組みのノード名は `TM_HM55_Rig`、スキン名は `TM_HM55_Skeleton` です（HM55 から変えていません）。
- 1 頂点あたりの影響する骨は、胴体 2 本・頭 3 本・髪 1 本まで（WEIGHTS_0 は 4 本分）。合計はすべて 1.0。

## 4. 動作クリップ（30fps）

| クリップ | 秒 | コマ | ループ | 腰の水平移動 | 備考 |
|---|---|---|---|---|---|
| `TM_HM55_Idle` | 2.0 | 61 | する | なし | 待機 |
| `TM_HM55_Run` | 0.667 | 21 | する | なし（その場で走る） | 接地中の足は地面を約 3.4〜4.1 m/s で後ろへ動く（`qa/QA_TABLES57.md` §4）。**ゲーム側で選手をこの速さで前へ動かすと、足が滑って見えない**。別の速さで走らせるときは再生速度を「移動速度 ÷ 約 3.8」にする |
| `TM_HM55_Kick` | 1.333 | 41 | しない | 前へ 0.16m | ボールに当たるのは 19〜20 コマ目あたり（目視。接触点は定義していない） |
| `TM_HM55_LookAround` | 3.333 | 101 | しない | なし | 首振り（左右・上下・傾き） |
| `TM_HM55_ThrowIn` | 1.5 | 46 | しない | 前へ 0.04m | |
| `TM_HM55_Header` | 1.4 | 43 | しない | なし | ジャンプの頂点は 17〜18 コマ目 |

- クリップ名は HM55 のままです（HM55・HM56・HM57 で同じ名前で再生できるように）。
- **HM57 で変えた点:** 接地の補正（各コマで腰の高さを調整し、支え足の裏が地面に乗るようにした）と、Kick で蹴り足が地面を通り抜けるコマの膝の曲げ。HM56 と値が違うのは、腰の位置のチャンネルと Kick の右すねの回転だけです。
- 腰（Hips）の位置にはクリップごとの上下の動きが入っています。ゲームの選手の位置（Root）は動かしていません（ルートモーションなし）。

## 5. 材質とテクスチャ

| 材質 | alphaMode | 両面 | テクスチャ（通常版 / 軽量版） |
|---|---|---|---|
| `TM_HM57_Kit_A`（ユニフォーム） | OPAQUE | する | 1024px PNG / 512px JPEG |
| `TM_HM57_BodySkin_T2`（腕脚の肌） | OPAQUE | しない | 512px PNG / 256px JPEG |
| `TM_HM57_Head_P0`（顔・首・耳） | OPAQUE | しない | 1024px PNG / 512px JPEG |
| `TMH55_H1_Cap`（髪の地） | OPAQUE | する | 512px PNG / 256px PNG |
| `TMH55_H1_CapEdge`（生え際のぼかし） | BLEND | する | 512×256 PNG / 256×128 PNG |
| `TMH55_H1_Cards`（前髪・襟足の毛束） | BLEND | する | 512px PNG / 256px PNG |

- 色テクスチャ（baseColor）のみです。法線マップ・ラフネスマップはありません（陰影の一部はテクスチャに焼き込み済み）。
- 半透明（BLEND）の髪は 2 つの材質です。描画順を入れ替えても画素がほぼ変わらないことを、HM55 で確認しています（HM57 では未確認）。
- 選手 1 人あたりの描画呼び出しは 6 回（材質ごとに 1 回）。

## 6. 部品の差し替え（顔・髪・肌色・ユニフォーム）

- 胴体・頭・髪は別々のモジュール GLB にもなっていて、**どれも同じ 22 本の骨（同じ名前・同じ逆バインド行列）** に付いています。
- 差し替えの方法（three.js での例。ブラウザテストで実際に動かしたコード: `webtest/index.html` の `assemble()`）:
  1. 胴体モジュールを読み込む（骨と動作はここから使う）。
  2. 頭と髪のモジュールを読み込み、その SkinnedMesh を、胴体の骨に **骨の名前で** 付け替える（`new THREE.Skeleton(胴体の骨を名前で並べたもの, 頭の boneInverses)` → `mesh.bind(...)`）。
  3. ユニフォームの差し替えは、胴体の `Kit` 材質（またはそのテクスチャ）を別のキットのものに置き換えるだけです（UV は全キット共通）。
- ブラウザでの確認結果（`qa/webtest57_result.json`）: モジュールから組んだ選手と、組み立て済みの選手を同じ姿勢（Run・Kick・Header・LookAround）で描くと、**画素の差は 0%** でした。見つからない骨は 0。ユニフォーム B への差し替えも動きました。
- 肌の色調は、顔のテクスチャ（`Head_<顔>`）と腕脚のテクスチャ（`BodySkin_<色調>`）の組で決まります。顔ごとに色調が決まっているので、差し替えるときは両方をそろえてください。

## 7. 軽量版（LOD）

- 軽量版は通常版と**骨・動作・材質の数が同じ**で、三角形とテクスチャだけが少ない版です。同じアニメーションの再生中に差し替えられます。
- 切り替える距離・画面の大きさは**決めていません**（iPhone 実機で測っていないため）。目安として比較画像 `S08`〜`S12` を用意しました。

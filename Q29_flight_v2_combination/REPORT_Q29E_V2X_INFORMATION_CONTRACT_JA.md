## 1. v2x の情報契約の局所テスト

### 1.1 契約（コードから、事実）

- `self.observedTouch` は、本人が目撃した最新の接触（seenTick・選手 id・チーム・部位）です。更新されるのは、(a) 本人自身が触れたとき、または (b) 本人がその tick に**球と触れた選手の両方を見ていた**ときだけです（`keeper_hands.mjs:27-29` の `recordHandTouches`）。見ていない接触では更新されず、古い記録が残ります。
- 検証（`validateObservedTouch`）が求めるのは、seenTick が現在より前で、選手が1〜22人、id・チーム・部位が正しいことだけです。鮮度の上限はありません。
- v2x の条件は「最接近が過去 かつ observedTouch の全員が本人」で、ドリブル種別も鮮度も球の証拠との前後関係も見ません。

### 1.2 テストの性質

- 保存 DTO に対する純関数の評価と、**observedTouch の欄だけを書き換えた反事実の DTO** による評価です。書き換えた DTO はすべてエンジン自身の `assertObservation` で再検証しました（無効 0 件）。
- これは**人工的な契約テスト**で、実試合での発生頻度ではありません。件数は「保存記録の中でこの条件に当たる判断の数」で、同じ場面の別版を含みます。
- 使った記録：Q27 の7本、7場面スイートの7本、Q29D の N5（V2）と N3（v2x）。本人の球で V2 と I17 の判断が違う DTO は 60 件（Q29B の 54 件＋追加記録の 6 件）、他人の球で違う DTO は 39 件。

### 1.4 利益対照と正常対照（`eval_e/anchor_counterfactuals.txt`）

| 場面 | 元の目撃 | I17 | V2 | v2x | 反事実 | v2x（反事実） |
|---|---|---|---|---|---|---|
| **N5 B10 12236（利益対照）** | B08 のパス（65 tick 前、B10 が目撃） | 汎用 | 計画（回収） | 計画（回収） | B08 の接触を**見ていなかった**（欄は本人のまま） | **汎用に戻る（回収を失う）** |
| **O2 A09 42316（利益対照）** | 自分のドリブル（10 tick 前） | 汎用 | 計画（継続） | 汎用（球外） | 他者の接触を目撃していた | 計画（継続） |
| **N1 B05 6170（正常対照）** | 自分のドリブル（7 tick 前） | 汎用 | 計画 | 汎用 | 他者の接触を目撃していた | 計画。ただし N1 では V2 でも同じパス・同じ受球だった |
| N2（正常対照） | ― | V2 の作用なし。3版とも同一 | | | | |

- N5 の窓では B10 自身の接触がなく、「見ていなかった」反事実は、目撃者欄が以前の自己接触のまま残る状況を模しています。B10 が B08 のパスを見ていたのは、12171 の時点で球と B08 の両方が視界にあったからです（記録の事実）。
- O2・N1 の反事実は「本人の球なのに他者の目撃が残る」状況で、契約上は起きません（自分の接触は必ず記録され、より新しい）。順序が逆の状況、すなわち**自分の接触の後に他者が触れたが見ていなかった**場合が、v2x が誤って拡張を外す経路です。

### 1.5 本人が知れる情報だけで何が起きるか（まとめ、事実）

| 状況 | v2x の動作 | I17 と比べて |
|---|---|---|
| 自分が押し出した球（目撃は自分） | 拡張なし（I17 と同じ汎用追走） | 同じ |
| 他者の球で、その接触を目撃した | V2 の拡張（計画） | V2 と同じ |
| 他者の球だが、その接触を見ていない（目撃欄は古い自己接触） | 拡張なし | **I17 と同じ。V2 の利益（N5 型の回収）を失う**。I17 より悪くはならない |
| 自分のパス・シュートの後 | 条件は当たるが、V2 自体が I17 と同じ | 同じ |
| 自己目撃が古い（60 tick 超） | 新しい方の目撃に関係なく、欄が自分なら拡張なし | 同じ |

- v2x の契約上の弱点は一つで、「見ていない他者接触」で V2 の利益を取りこぼすことです。誤って拡張を**加える**経路はありません（自分の接触は必ず記録されるため）。
- これらの記録では、見ていない他者接触が間にあった DTO は 0 件でした（Q29D §2）。頻度は未検証です。

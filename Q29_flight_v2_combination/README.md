# Q29 出し手の飛行時間連動 × 受球V2：同じ状態からの4条件比較

報告書は `REPORT_Q29_FLIGHT_V2_COMBINATION_JA.md`、事前に固定した条件は `PREREGISTERED_Q29.md` です。

## 何をしたか

- 4条件を、同じ開始状態から短い窓で比べました。
  - 基準
  - 出し手だけ（既存の飛行時間連動）
  - 受け手だけ（既存の受球V2）
  - 両方（今回作った隔離コピー）
- 両方版は、既存の2つの変更を合わせたものです。変えたのは4ファイルで、`combo_source/` に入っています。
- 新しい係数や規則はありません。名札は独自のものを付け、witness の検査は外していません。
- 原本の上書き、正式統合、採否の変更、90分試合はしていません。

## 中身

| 場所 | 内容 |
|---|---|
| `combo_source/` | 両方版で変えた4ファイル、エンジンの差分、元のファイルとの SHA |
| `tools/build_combo.sh` | 3版セットのコピーに両方版を作る（バイト単位で再現） |
| `tools/` | 受け付けの確認、和集合の確認、記録、追跡、再現の確認（読み取りと記録だけ） |
| `eval/` | 確認の記録、各実行の確認値、追跡と時系列 |

20条件の全フレーム・全行の記録は大きいので入れていません。`tools/run_matrix.sh` で作り直せます。

## 結論（短く）

- 比較はできました。ただし開始状態は5つで、12235 などは拒否されたので未実施です。
- 2つの要因が同じ判断に同時に効いた例はありません。
- 42190 の改善は出し手の要因だけで起き、V2 は関与していません。
- V2 による球外の例（12355）は、飛行時間を加えても受けられませんでした。
- 60288 は、同じ状態からなら先読み 0.35秒でも球外でした。
- 組合せの結果は、単独の作用が順に効いたものとして説明できます。

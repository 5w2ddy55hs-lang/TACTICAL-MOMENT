# Q29C：本人のドリブル後に受球V2が作用した場面の追跡と、隔離候補 v2x の比較

Q29B の続きです。受球V2が「本人が押し出した球」に作用した場面を、タッチの早さだけでなく、その後の選択肢・味方と相手の反応・次のプレーまで追いました。そのうえで、「本人が最後に目撃したタッチが自分なら V2 の拡張を使わない」隔離候補（v2x）を作り、同じ開始状態から基準・V2 と比べました。

- 原本・AI・正式採否は変更していません。候補は研究用の隔離コピーで、独自の名札を付け、保存の拒否は回避していません。
- 候補を走らせる前に、理由と比較条件を `PREREGISTERED_Q29C.md` に固定しました。
- 件数の扱い：15,104 件の DTO 比較と 81 件の差は、同じ場面の別版を含む保存記録の集まりです。独立したプレー数や試合中の発生頻度とは扱いません。5機会・6区間も関連した少数です。
- 60288（O5）は、同じ途中状態から先読み 0.35 秒に戻しても球外だったので、長い先読みだけを原因とはしません（Q29 §4.3(c)）。

記号：DP＝専用の受球計画／FE t＝汎用探索で t 秒の点が到達可能／EX＝2秒先の末尾点。20 tick/秒。

## 0. 要点

1. **V2 が本人のドリブル後に作用した6区間を次のプレーまで追った結果（事実）：** 早いタッチの後、基準より良い次のプレーになった例は V2 単独の記録にはありませんでした。O1 は相手の制御（基準も相手、時刻が違う）、O3 は球外（基準は受球成功）、O4 は球外（基準はドリブル継続）、O2 は3区間ともドリブル継続（基準も継続）。唯一「受けられた」のは Q29 の両方版（O1、飛行時間連動つき）で、V2 単独の作用ではありません。
2. **球外の2件は、キックの誤差ではなく I17 の構造が別の時刻に現れたものです（事実と推論）。**
   - O4：ドリブルの方向候補（前・斜め前2本）は相手から最も遠い方向を選び、タッチラインを考えません。これらの記録の 83 本のドリブルのうち、目標がフィールド端に丸められたものは 4 本で、そのうち 3 本が誰も触れずに球外になりました。球外 3 本はすべてこの型で、**基準の記録にも 1 本あります**（O1 基準 42330 A09 → 42362 スローイン）。V2 はタッチの時刻と位置を変え、その型に当たる機会を作りました。キックの角度・威力の誤差は小さい値です。
   - O3：早まったパス（12355）は 0.35 秒の固定先読みで、走る受け手の前を通り過ぎました（Q26 で確認した出し手と受け手のずれ）。パスそのものは早いタッチがなければ存在しません。
   - 「自然なミス」と呼べる要素（誤差の大きいキック）は、どちらにも見つかりませんでした。繰り返す構造は V2 固有ではなく I17 側にあり、V2 はそれが現れる時刻を動かした、というのが今回の読みです。
3. **候補 v2x（1行の追加）：** `tClosest ≤ 0` かつ本人が最後に目撃したタッチが自分なら計画を返さない。全 DTO で、該当 526 件は I17 と一致、それ以外 14,578 件は V2 と一致、違反 0 件。V2 と I17 の差 81 件のうち、v2x で残るのは他人のタッチの後の 27 件だけです。
4. **同じ5つの開始状態からの比較（事実）：**
   - O1・O2・O3・O5 では、v2x は**基準と全フレーム・全行・終わりの状態まで同一**でした。これらの機会で V2 が変えていたものは、すべて本人のドリブル後の作用だったことになります。
   - O4 では、v2x は 60089 の A09（相手 B09 のドリブルの球が自分の横を過ぎた直後）で基準と分かれました。これは V2 が狙う「他人の球」の場面で、v2x は V2 と同じ計画を出し、A09 は基準より 5 tick 早く球を得ました（60124 vs 60129）。その後の展開は分かれ、良し悪しは判定しません。
   - つまり v2x は、この5機会では「本人の球への作用を外し、他人の球への作用（O4 の A09）を残す」という設計どおりに動きました。
5. **受け手への有益な作用を失わないか：** O4 の A09 の1件が、これらの記録で V2 が他人の球に作用した唯一の実行例で、v2x でも残っています。それ以外の V2 の受け手側の改善例（L21 研究の回収例など）は、この記録には含まれていないので**未検証**です。
6. **未確定・未検証：** 早いタッチの良し悪し（サッカーの評価）、全試合での頻度、v2x の全試合での振る舞い、飛行時間連動との組合せ。

## 2. 球外の2件：自然なミスか、繰り返す構造か

### 2.1 O4（60056 のドリブルが球外）

**事実**
- 60053 の B09 の EBI ドリブル意図の目標は (72.4, 67.8)。y=67.8 はフィールド端への丸め値です。B09 は y=64.6、最寄りの相手 A07 は 4.2m。
- ドリブルの方向候補は前・斜め前2本の 7m 先で、相手から最も遠い方向を選びます（`outgoing_candidates_legacy.mjs:11-13`）。タッチラインは考慮されません。
- 60056 のキック速度 (3.71, 2.96)、角度誤差 −0.014 rad、威力 0.978。基準の 60083 のキックは (4.31, 0.17)、誤差 0.049 rad、威力 1.011。どちらも誤差は小さい。
- これらの記録（Q29 の7本と7場面）の 83 本のドリブルのうち（`eval/touchline_dribbles.txt`）：

  | 項目 | 本数 |
  |---|---:|
  | 目標がフィールド端に丸められた | 4 |
  | そのうち誰も触れずに球外 | 3 |
  | 球外になったドリブルの総数 | 3（すべて丸められた目標） |
  | 端から 4m 以内で蹴られた | 26（丸められたのは 4） |

  球外の3本：基準 O1 42330 A09（→42362 スローイン）、V2 O4 60056 B09（→60083）、7場面 outlet_unreached 42330 A09（基準 O1 と同じ記録）。

**推論**
- 「タッチライン近くで、内側に相手がいると、ドリブルの目標が端に丸められ、球外になりやすい」は I17 の構造で、基準の記録にも現れています。O4 の球外は、V2 の早いタッチがこの構造に当たる時刻と位置を作ったものです。V2 固有の欠陥とも、キック誤差による自然なミスとも読めません。
- この構造の頻度（83 本中 4 本）は、これらの窓での値で、全試合の頻度ではありません。

### 2.2 O3（12355 のパスが球外）

**事実**
- 早まったパスは 0.35 秒の固定先読み、受け手 A09 は 5.7m 先を 6.8 m/s で走行中。真の最接近 1.75m（12390）、12408 に球外（Q27 §4 の V2 反例と同じ記録）。
- 基準の 12367 のパスは、受け手が 7.1m、専用計画 DP で 0.65m まで寄って受球。

**推論**
- 外れ方は Q26 で確かめた「固定先読みが走る受け手の後ろ／前にずれる」型です。早いタッチが作ったパスに、出し手側の既知の構造が当たりました。Q29 の両方版（先読み 1.40 秒）では相手 B07 の制御になり、球外は消えましたが受球はできていません。

### 2.3 区別のまとめ

| 観点 | 判定 |
|---|---|
| キック誤差による自然なミス | 2件とも誤差は小さく、該当しない |
| 繰り返す構造 | ある。ただし I17 側（ドリブルの方向候補、固定先読み）で、基準の記録にも現れる |
| V2 の役割 | タッチの時刻と位置を動かし、その構造に当たる機会を変えた。良い方へも悪い方へも動き得るが、この記録で良い方へ動いた例はない |

## 3. 候補 v2x

### 3.1 作る理由（事前登録どおり）

1. V2 の差が現れた 81 件のうち 54 件が、本人が押し出した球への判断でした（Q29B）。
2. I17 はその場面を「専用計画なし・汎用の追走」と扱い、V2 の拡張が狙うのは他人の球が通り過ぎた直後の回収と読めます。
3. 両者を分け、他人の球への作用を保ったまま、自分の球への作用だけを外した動きを見ます。

個別例外ではありません。条件は本人の観測（`self.observedTouch`：本人が目撃した最新のタッチの id）だけで決まる一般則です。

### 3.2 変更（C1、`eval/C1_v2x_vs_v2.diff`）

V2 の `reception.mjs` 17 行目の直後に 1 行：

```js
if(tClosest<=0&&p.observedTouch&&p.observedTouch.players.length>0&&p.observedTouch.players.every(q=>q.id===p.id))return null;
```

ほかの差は名札（`TM_RESEARCH_Q29C_V2X_SAVE/1`）だけです。

## 4. 事実・推測・未検証

**事実**
- 6区間の次のプレーまでの経過（§1）。
- 球外2件の原因となった処理（ドリブルの方向候補の端への丸め、固定先読み）と、同型が基準の記録にもあること（§2）。
- v2x の構成（1行）と C1〜C4。O1・O2・O3・O5 で v2x ＝ 基準、O4 で他人の球への作用だけが残ること。

**推測**
- 球外2件は自然なミスではなく、I17 側の構造に V2 の早いタッチが当たったもの。
- V2 の作用のうち、これらの記録で実際に展開を変えたのは本人の球への作用がほとんどで、他人の球への作用は O4 の1件。

**未検証**
- 早いタッチと v2x の良し悪し（Astra）、頻度（Sol）。
- v2x を他の seed・90分で走らせたときの振る舞い。V2 の受け手側の既知の改善例（L21 研究）が v2x でも残るか。
- v2x と飛行時間連動の組合せ。
- ドリブルの方向候補がタッチラインを考えない構造の全試合での頻度。これは受球の領域ではなく、別の担当の判断になります。
